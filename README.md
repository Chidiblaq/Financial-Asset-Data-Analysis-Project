# 📈 Financial Asset Data Analysis Project

## Overview

This project analyzes the historical performance of multiple financial assets over a five-year period (August 2019 – August 2024) using Python. The analysis compares the returns and risk characteristics of stocks, cryptocurrency, bonds, and market indices through exploratory data analysis, return calculations, and investment performance evaluation.

The objective is to demonstrate how data analytics can be applied to financial markets to evaluate investment opportunities and compare asset classes using historical market data.

---

## Objectives

- Analyze historical price movements of multiple financial assets.
- Compare investment performance across different asset classes.
- Calculate and visualize returns over time.
- Evaluate hypothetical investment outcomes.
- Understand the relationship between investment risk and return.

## Key Analyses

### Historical Price Analysis

- Visualized historical price movements over five years.
- Compared trends across stocks, cryptocurrency, bonds, and market indices.
- Examined how different asset classes performed under changing market conditions.

### Investment Performance

Simulated investing **$1,000** in each asset at the beginning of the study period and calculated:

- Number of shares purchased
- Ending portfolio value
- Total profit/loss
- Percentage return

### Return Analysis

Calculated:

- Simple Returns
- Daily Returns
- Annualized Returns

to evaluate the long-term performance of each investment.

### Asset Comparison

Compared the performance of:

- Technology stocks
- Traditional industrial stocks
- Cryptocurrency
- Bond ETFs

to understand the trade-off between risk and return.

### Market Index Analysis

Compared the long-term performance of:

- S&P 500
- Russell 2000

to evaluate the performance of large-cap versus small-cap U.S. equities.

---

## Example Insights

- Bitcoin produced the highest overall return but also exhibited the greatest volatility.
- Amazon significantly outperformed Ford over the analysis period.
- Bond ETFs generated lower but more stable returns compared to equities and cryptocurrency.
- Percentage returns provide a more meaningful comparison than raw asset prices.
- Annualized returns offer a standardized metric for comparing investments across different asset classes.
